# gptcgt

Multi-model AI coding terminal — runs multiple AIs on your code, picks the best solution with proof, shows you exactly what it costs.

## Quick Start
```bash
pip install -e .[dev]
gptcgt
```

## Tech Stack
- Python 3.11+
- Textual (TUI framework)
- LiteLLM (multi-model abstractions)
- tree-sitter (parsing)
- E2B (sandbox environments)
